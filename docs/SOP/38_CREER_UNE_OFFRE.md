# SOP 38 · Créer une offre commerciale pour une Solution

1. Agence Elite → Offres et prix (Super Admin) → nouvelle offre de la solution.
2. Modules inclus : seulement des modules **Disponibles** ou **Bêta**, avec toutes leurs dépendances
   (la base refuse sinon). Le socle est toujours inclus.
3. Prix : jamais codés en dur ; ils se règlent dans l'offre (acquisition, mise en service, mensuel, annuel).
   Le support est facturé à part.
4. Option « Personnalisation de l'apparence » : se règle par client (Clients → fiche → Apparence → case
   « Le client peut régler lui-même… »), pas dans le code.
5. Vérifier sur un établissement de démonstration : Paramètres → Applications montre « Dans l'offre ».
