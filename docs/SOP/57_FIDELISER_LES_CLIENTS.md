# SOP 57 — Gérer la fidélité des clients

1. **Activer** (Agence Elite) : Modules › Fidélité › Accorder, Activer.
2. **Régler** (gérant) : Paramètres › Réglages des modules › Fidélité : tranche, points par tranche, valeur d'un point, minimum.
3. **Gagner** : en caisse, choisir le client avant de valider la vente. Les points s'ajoutent seuls.
4. **Récompenser** : Relations › Fidélité › client › Utiliser les points ; accorder la remise ou le cadeau en caisse et
   noter le numéro du ticket dans « Récompense accordée ».
5. **Corriger** (gérant) : Ajouter des points (négatif pour retirer), toujours avec un motif.
6. **Annulation** d'une vente : les points sont retirés automatiquement.
