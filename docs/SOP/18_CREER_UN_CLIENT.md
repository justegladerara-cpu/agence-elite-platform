# SOP 18 · Créer un client

Espace **Agence Elite → Clients → Nouveau client**.

1. Nom de l'entreprise, contact, téléphone, e-mail, ville, pays.
2. Enregistrer : la fiche client s'ouvre (onglets Établissements, Licences, Activité).
3. Ajouter un établissement : [SOP 19](19_CREER_UN_ETABLISSEMENT.md).

Un client n'est jamais supprimé : menu ••• → **Archiver** (masqué des listes, données conservées,
réactivable). Suspendre = accès en lecture seule ([SOP 23](23_SUSPENDRE_REACTIVER.md)).
