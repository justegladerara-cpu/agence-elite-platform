# SOP 46 — Demander, commander, réceptionner, payer un fournisseur

1. **Fournisseur** : Contacts › Nouveau, type « Fournisseur » (ou « Client et fournisseur »).
2. **Demande** (dépôt, responsable de Hub) : Achats › Demande d'achat. Articles suivis en stock uniquement
   (les autres frais passent en Dépenses). Le gérant reçoit la demande dans l'onglet « Demandes ».
3. **Approuver** (gérant, comptable) : ouvrir la demande › Approuver, choisir le fournisseur. Elle devient
   une commande BC- en brouillon ; le demandeur est notifié. Refuser = menu ⋯ › Refuser (motif, notifié).
4. **Commande directe** : Achats › Nouvelle commande (ou onglet Réapprovisionnement › Préparer la commande).
   « Marquer envoyée » quand le bon part chez le fournisseur : les lignes se figent, l'échéance se calcule.
5. **Réceptionner** (dépôt) : Réceptionner, saisir ce qui est arrivé et le coût réel, le n° de BL.
   Le stock du Hub augmente, le coût d'achat des articles se met à jour (paramètre), la commande passe
   « Reçue en partie » ou « Reçue ». Une réception est définitive : erreur = ajustement de stock motivé.
6. **Payer** (gérant, comptable) : Payer, montant (acompte possible jusqu'au total), mode, référence.
   Erreur = menu ⋯ du paiement › Annuler (motif). Les paiements fournisseur ne sont pas des dépenses.
7. **Annuler** une commande : seulement sans réception ni paiement (motif obligatoire).
8. Suivi : cartes « Dû aux fournisseurs / À recevoir / Demandes / Sous le minimum », tableau de bord Achats,
   export CSV, pièces jointes (proforma, BL, facture fournisseur) sur chaque commande.
