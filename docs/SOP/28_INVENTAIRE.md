# SOP 28 · Faire un inventaire

Page **Stock** → onglet **Inventaires** → **Nouvel inventaire**.

1. Choisir le Hub. La liste des articles s'affiche avec la quantité attendue.
2. Compter physiquement, saisir la quantité comptée.
3. Valider avec un motif (ex. « inventaire mensuel ») : chaque écart devient un mouvement
   d'ajustement tracé (numéro `INV-…`). Rien n'est écrasé.

Conseil : faire l'inventaire caisse fermée, après le ticket Z.
