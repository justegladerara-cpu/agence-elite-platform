# SOP 53 — Prendre et suivre un rendez-vous

1. **Activer** (Agence Elite, hors solution Services) : Espace éditeur › établissement › Modules › Agenda › Accorder, Activer.
2. **Prendre** : Agenda › Rendez-vous (ou « + » sur un jour) : client, objet, personne, date et heure, durée, prestation.
   Si la personne est déjà prise, la base refuse : choisir un autre créneau.
3. **Confirmer** après l'appel au client : fiche › Confirmer.
4. **Après le rendez-vous** : Honoré, ou Absent (motif), ou Annuler (motif). Rien ne se supprime.
5. **Facturer** : fiche › Facturer → facture brouillon dans Facturation, à émettre puis encaisser (SOP 45).
6. **Planning** : filtre « Mes rendez-vous » ou par personne ; onglet Liste pour rechercher.
