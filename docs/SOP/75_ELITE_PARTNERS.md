# SOP 75 · Elite Partners (partenaires, clés, commissions)

Détail : [`../ELITE_PARTNERS.md`](../ELITE_PARTNERS.md).

1. **Recruter** : partager `#/partenaire` (ou le lien de recrutement d'un partenaire), puis Elite Partners › Partenaires ›
   « Valider l'inscription ». Ou « Nouveau partenaire » (actif tout de suite ; relié à son compte par l'e-mail).
2. **Vendre** : le client paie Agence Elite (installation + licence) → « Générer des clés » avec le bon modèle et le
   partenaire → envoyer la clé ou le lien d'activation.
3. **Installer** : le partenaire ouvre `#/activer?cle=…` sur l'ordinateur du client, crée le compte du client et son
   établissement. Le premier ordinateur est enregistré.
4. **Renouveler** : fiche établissement › Licence › renouveler avec le montant reçu → la commission suit seule.
   Ou nouvelle clé (Paramètres › Licence › « Activer une clé »).
5. **Payer** : chaque mois, Partenaires › « Payer » (commissions « à payer ») avec la référence Mobile Money.
6. **Problème** : clé bloquée (licence suspendue), commission annulée avec motif, partenaire suspendu ; changer
   d'ordinateur = le partenaire ou le Super Admin « libère » la place.
