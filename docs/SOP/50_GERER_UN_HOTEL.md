# SOP 50 — Hôtel : chambres, réservations, arrivées, départs

1. **Préparer** (gérant) : Chambres › Types et tarifs (Standard, Suite… tarif de la nuit, capacité), puis Chambres
   (numéro, étage, type).
2. **Réserver** : Réception › Réservation (ou clic sur une case libre du Planning) : client enregistré ou nom +
   téléphone, dates, type, chambre facultative, tarif. « Complet » = plus aucune chambre de ce type cette nuit-là.
3. **Accueillir** : Réception › Aujourd'hui › le client › Arrivée › choisir une chambre propre.
4. **Pendant le séjour** : Prestation (minibar, petit-déjeuner, transfert…) ; erreur : Annuler (motif). Si nécessaire :
   ⋯ › **Prolonger le séjour** (disponibilité contrôlée) ou **Changer de chambre** (même type, chambre propre, motif
   obligatoire ; l'ancienne passe à nettoyer).
5. **Départ** : Départ et facture › Émettre la facture › sur la facture : Encaisser (SOP 45). La chambre passe
   « à nettoyer » et l'équipe d'entretien est prévenue.
6. **Entretien** : Chambres › Entretien : Commencer › Propre ; Hors service exige un motif (exclue des disponibilités).
7. **Imprévus** : client absent le jour prévu : ⋯ › Client absent ; annulation : ⋯ › Annuler (motif) ;
   changement de dates ou de chambre avant l'arrivée : ⋯ › Modifier.
