# SOP 41 · Gérer les catégories de modules

- Table `categories_modules(id, nom, description, icone, ordre)` ; écran Catalogue → Catégories (Super Admin).
- Catégories prévues : socle, reporting, ventes, pos, stock, achats, facturation, finances, comptabilité, crm,
  rh, restaurant, hôtel, e-commerce, site web, marketing, projets, documents, support.
- L'identifiant ne change pas ; le nom, l'icône et l'ordre si. Une catégorie sert au classement (catalogue,
  page Applications du client), jamais aux droits.
