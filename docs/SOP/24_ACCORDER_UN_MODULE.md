# SOP 24 · Accorder un module en plus

1. Établissement → onglet **Modules** → module optionnel → **Accorder** (motif).
2. Les rôles qui ont la permission voient la page à leur prochaine ouverture.
3. **Retirer** : la page disparaît et la base refuse les écritures ; les données restent.

Catalogue global : Agence Elite → **Modules** (statut actif / en préparation / futur / retiré,
proposé ou non aux clients). Un module « en préparation » ne peut pas être accordé.

## Module complémentaire (module d'une autre solution)

Exemple : un établissement « commerce » qui ouvre une salle reçoit **Salle** et **Cuisine** sans changer de solution
(la solution d'un établissement ne change jamais) ni perdre ses ventes, son stock ou sa caisse.

1. Tarif : Agence Elite → **Offres et prix** → **Options de modules** → module → prix mensuel, annuel, mise en service.
2. Établissement → onglet **Modules** → section **Modules complémentaires** → **Accorder** → **motif obligatoire**
   (ex. « Option restaurant signée le … »).
3. La base ajoute les dépendances (Cuisine → Salle → Caisse, Articles…), active les modules et note le montant de
   l'option dans l'historique de la licence. Les rôles Serveur et Cuisinier deviennent invitables.
4. **Retirer** (motif obligatoire) : le module est masqué, ses données (tables, commandes, affectations) restent et
   réapparaissent s'il est de nouveau accordé. Un module dont un autre dépend se retire après celui-ci.
5. Le client ne peut jamais s'accorder un module lui-même ; une licence suspendue bloque aussi les modules complémentaires.
