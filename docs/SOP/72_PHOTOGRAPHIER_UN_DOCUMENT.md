# SOP 72 — Photographier un document et l'envoyer avec un réseau instable

**Qui :** toute personne qui enregistre une dépense ou joint un document. **Où :** Dépenses › Nouvelle dépense, et
« Ajouter un document » sur une fiche (facture, contact, employé…). Aucun réglage.

## Photographier un justificatif
1. Nouvelle dépense › **Photo du justificatif** : sur téléphone, l'appareil photo s'ouvre.
2. L'écran de recadrage s'affiche : faire glisser les quatre coins sur les bords du ticket (au clavier : se placer sur
   un coin avec Tab, puis les flèches). **Pivoter** si la photo est de travers d'un quart de tour.
3. **Valider le recadrage**, puis enregistrer la dépense. Pour reprendre : bouton **Recadrer** sous la vignette.

## Joindre une photo à une fiche
Ajouter un document › choisir la photo › **Recadrer la photo** (facultatif) › Valider › Ajouter. Le nom se termine
alors par « .jpg ».

## Si le réseau coupe pendant l'envoi
1. Le message « Connexion perdue : l'envoi reprendra tout seul dès le retour du réseau » s'affiche : garder la fenêtre
   ouverte, ne pas rechoisir le fichier.
2. L'envoi repart tout seul (4 essais). Si le fichier était déjà arrivé, il n'est pas envoyé deux fois.
3. Après 4 essais : « l'envoi n'a pas abouti » ; le fichier reste choisi, cliquer **Ajouter** quand le réseau revient.

## Ce qu'il ne faut pas faire
- Fermer la page pendant « Connexion perdue » : l'envoi est alors perdu.
- Envoyer la photo d'un document d'une autre personne sans raison : les pièces jointes restent dans le dossier.
