# SOP 61 — Utiliser l'assistant

**Qui :** gérant ou responsable (droit `assistant.lire`). **Où :** menu Pilotage › **Assistant**.

## Activer (Agence Elite)
1. Espace Agence Elite › client › établissement › Licence : accorder le module **Assistant** (option, motif tracé).
2. Le module apparaît alors dans le menu des gérants et responsables.

## Chaque matin (client)
1. Ouvrir **Assistant**. La liste commence par les points urgents.
2. Cliquer une ligne : l'écran concerné s'ouvre, déjà filtré.
3. Traiter, puis revenir et cliquer **Actualiser**.

## Régler les seuils
Paramètres › Applications › **Assistant** : nombre de jours analysés, nombre d'annulations avant alerte, remise jugée
forte. Enregistrer.

## Bon à savoir
- L'assistant ne modifie rien : il lit et calcule.
- Chacun ne voit que ce que son rôle lui permet de voir ailleurs.
- « Annulations répétées » n'est pas une accusation : c'est un point à vérifier avec la personne.
