# SOP 52 — Créer et publier le site web d'un client

1. **Accorder le module** (Agence Elite) : Espace éditeur › établissement › Modules › Site web › Accorder, puis Activer.
2. **Régler** (gérant) : Site web › Réglages : nom, adresse (ex. `salon-prestige`), couleur, thème, description.
3. **Créer les pages** : Site web › Page : titre et adresse (`services`, `contact`…). La première est l'accueil.
4. **Construire** : ouvrir la page › Ajouter un bloc (bandeau, texte, services, produits, témoignages, FAQ, contact…)
   › remplir › ↑ ↓ pour l'ordre › Enregistrer le brouillon. Liens : `/contact`, `/boutique`, `https://…`, `tel:+242…`.
5. **Vérifier** : Aperçu (le brouillon tel qu'il sera vu).
6. **Publier** (gérant) : Publier sur chaque page ; puis Réglages › cocher « Site en ligne ». Partager « Voir le site ».
7. **Modifier ensuite** : on change le brouillon sans toucher au site ; « Modifiée, non publiée » tant qu'on n'a pas publié.
8. **Messages** : Site web › Messages (notification) : rappeler le visiteur, puis Marquer traité.
9. **Retirer** : une page : « Retirer la page du site » ou l'archiver ; tout le site : décocher « Site en ligne ».
10. **Nom de domaine propre** : demande à Agence Elite (configuration DNS et Cloudflare, hors plateforme).
