# SOP 29 · Clôturer une caisse (ticket Z)

1. **Caisse** → Fermer la session : compter l'espèce et saisir le montant réel.
2. L'écart (réel − attendu) s'affiche. Un écart doit être expliqué dans la note.
3. Le ticket Z est créé : non modifiable, imprimable depuis **Clôtures**.
4. En multi-Hub, la page Clôtures se filtre par Hub.

Une vente d'une session clôturée ne peut plus être modifiée ; une erreur se corrige par un avoir / une annulation tracée.
