# SOP 58 · Personnaliser les pages de connexion

**Qui** : Super Admin (plateforme) ; Super Admin ou Admin (client, établissement). **Durée** : 5 à 15 min.

1. Espace Agence Elite › **Identité et apparence** › onglet **Pages d'authentification**.
2. **Niveau** : « Plateforme » pour tout le monde, ou un client, ou un de ses établissements.
3. Modifier dans l'ordre : **Identité** (nom, monogramme, sous-titre, logo), **Textes** (choisir la page), **Apparence**
   (couleur, disposition, fond, image), **Boutons et liens**. Laisser vide = garder la valeur héritée (affichée en gris).
4. Regarder l'**aperçu** à droite : changer de page, passer en **Téléphone**.
5. **Enregistrer le brouillon** (personne ne le voit encore), puis **Publier** : c'est en ligne tout de suite.
6. Client ou établissement : transmettre le lien `…#/connexion/<adresse>` (adresse réglée dans la fiche du client, ou ici pour un établissement).

**Revenir en arrière** : onglet **Publication** › Historique › « Remettre cette version dans le brouillon », vérifier, Publier.
Tout effacer : « Revenir aux valeurs par défaut », puis Publier.

**Contrôle** : ouvrir le lien dans une fenêtre privée (texte, logo, couleur), sur téléphone aussi.

**Ne pas faire** : coller du code (refusé), mettre un lien en http:// (refusé), promettre une double authentification (n'existe pas).
