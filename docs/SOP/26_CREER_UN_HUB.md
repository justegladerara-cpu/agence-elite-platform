# SOP 26 · Ouvrir une boutique ou un dépôt (Hub)

Un **Hub** = un lieu physique de l'établissement : boutique, dépôt, ou les deux (mixte).
Un petit commerce n'a qu'un Hub : l'écran n'en parle alors jamais.

1. Établissement → **Hubs** (ou espace Agence Elite → établissement → onglet Hubs) → **Nouveau Hub**.
2. Nom, type (point de vente : vend ; dépôt : stocke ; mixte : les deux), adresse.
3. Boutique ou mixte : **Nouvelle caisse** sur ce Hub.
4. Équipe : cocher les Hubs autorisés pour chaque membre (aucune case = tous).
5. Le sélecteur de Hub apparaît en haut dès qu'il y a deux Hubs actifs.

Désactiver un Hub : possible s'il n'a plus de caisse active ; il n'est jamais supprimé et son historique reste.
Le Hub principal ne peut pas être désactivé.
