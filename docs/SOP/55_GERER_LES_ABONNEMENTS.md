# SOP 55 — Gérer les abonnements d'un client

1. **Activer** (Agence Elite) : Modules › Abonnements › Accorder, Activer (Facturation doit être active).
2. **Formule** : Abonnements › Formules › Formule : nom, prix, périodicité.
3. **Abonner** : Abonnés › Abonner un client : client, formule, prix négocié éventuel, date de début.
4. **Facturer** chaque mois : « Facturer les périodes dues » → une facture par période, jamais deux.
5. **Encaisser** sur chaque facture (Facturation, SOP 45). Les impayés sont au tableau de bord.
6. **Suspendre / reprendre / résilier** : fiche de l'abonné (motif obligatoire). Les factures émises restent.
