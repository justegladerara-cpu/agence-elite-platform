# SOP 54 — Traiter une demande client (ticket)

1. **Activer** (Agence Elite) : Modules › Support et demandes › Accorder, Activer. Délais : Paramètres › Réglages des modules.
2. **Ouvrir** : Support › Ticket : sujet, client, canal, priorité. L'échéance de réponse se calcule seule.
3. **Assigner** : fiche › Suivi › personne (elle est notifiée) ; ajuster la priorité si besoin.
4. **Échanger** : écrire la réponse donnée au client ; cocher « Note interne » pour ce que le client ne voit pas.
5. **Statut** : En cours, Attente client, puis Résolu en décrivant la solution, puis Fermé.
6. **Rouvrir** si le problème revient (motif). **Suivre** : filtres À traiter, En retard, Mes tickets.
7. **Réponses types** : Support › Réponses et aide › Ajouter (responsable). Dans un ticket, « Réponse type » insère le texte.
8. **Escalader** si le client est bloqué : fiche › Escalader, avec le motif. La priorité monte et les responsables sont prévenus.
9. **WhatsApp** : écrire la réponse, « Ouvrir dans WhatsApp », envoyer, puis « Ajouter » pour la garder dans le ticket.
10. **Rendez-vous** : fiche › Prendre un rendez-vous (module Agenda actif).
11. **Clore avec le client** : une fois résolu, demander au client si c'est réglé : « Le client confirme » (fermé) ou
    « Pas résolu pour le client » (rouvert). Noter sa satisfaction de 1 à 5.
12. **Affectation automatique** : Paramètres › Réglages des modules › Support (désactivée par défaut).
