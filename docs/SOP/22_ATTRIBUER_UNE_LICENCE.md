# SOP 22 · Vendre et attribuer une licence

Établissement → onglet **Licence** → **Attribuer / renouveler**.

1. Choisir l'offre (acquisition, mensuel, annuel, essai). Les prix viennent de **Offres et prix**
   (modifiables par le Super Admin uniquement, jamais écrits dans le code).
2. Vérifier montant, début, échéance. Le support est facturé à part.
3. Enregistrer : un événement non modifiable est ajouté à l'historique de la licence.

Le tableau Agence Elite affiche l'**activité contractuelle** (montants inscrits), pas l'argent encaissé.
Échéance passée : l'établissement passe en lecture seule, rien n'est supprimé.
