# SOP 60 — Mettre en service une agence immobilière

Référence fonctionnelle : [docs/IMMOBILIER.md](../IMMOBILIER.md).

1. **Créer l'établissement** avec la solution « Immobilier » (une agence = un établissement ; un réseau = plusieurs
   établissements du même client). L'offre d'essai « Gestion immobilière » active Biens, Locations, Maintenance.
2. **Identité** : nom commercial, adresse, téléphone, logo (Paramètres → Entreprise). Ils figurent sur les quittances.
3. **Équipe** : directeur d'agence = « Responsable d'établissement » ; gestionnaires = « Gestionnaire locatif » ;
   commerciaux = « Agent commercial » ; comptable = « Comptable » (reversements).
4. **Saisie de départ** (par l'agence, ou import validé par le client — jamais de données réelles en démo) :
   propriétaires (commission) → immeubles → lots → locataires → baux (date de début réelle ; échéancier automatique).
5. **Reprise des loyers déjà payés** : un encaissement par locataire, à la date réelle, avec la référence.
6. **Vérifier** : Vue d'ensemble (taux d'occupation, impayés) cohérente avec le registre de l'agence ; une quittance
   imprimée relue par le directeur.
7. Premier **reversement** préparé en présence du comptable, puis marqué versé avec la référence du paiement.

Interdits : modifier une donnée de production à la main ; supprimer un encaissement (on l'annule avec un motif).
