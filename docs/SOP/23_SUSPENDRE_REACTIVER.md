# SOP 23 · Suspendre ou réactiver

- **Licence** : onglet Licence → Suspendre (motif obligatoire). L'établissement garde la lecture,
  toute écriture est refusée par la base. Réactiver remet l'écriture.
- **Client** : fiche client → ••• → Suspendre / Réactiver / Archiver (confirmation demandée).
- **Établissement** : onglet Infos → statut.

Aucune de ces actions ne supprime de données. Tout est tracé dans `journal_audit` et `licence_evenements`.
