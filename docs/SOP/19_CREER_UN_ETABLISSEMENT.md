# SOP 19 · Créer un établissement

Fiche client → **Nouvel établissement**.

1. Nom, solution (Commerce), ville, devise.
2. À la création, la base crée automatiquement le **Hub principal**. Ajoutez-lui une caisse (onglet Hubs → Nouvelle caisse).
3. Onglet **Licence** : un essai de 30 jours démarre tout seul ; attribuer la vraie formule ([SOP 22](22_ATTRIBUER_UNE_LICENCE.md)). Sans licence valide : lecture seule.
4. Onglet **Équipe** : inviter le responsable ([SOP 20](20_CREER_GERER_UTILISATEURS.md)).
5. Onglet **Hubs** : ajouter d'autres boutiques ou un dépôt seulement si le client en a ([SOP 26](26_CREER_UN_HUB.md)).
6. Onglet **Mise en service** : suivre la liste, puis **Déclarer la mise en service**.

Processus commercial complet : [`docs/PROCESSUS_CLIENT.md`](../PROCESSUS_CLIENT.md).
