# Guide de prise en main (Solution Commerce)

## Se connecter
Ouvrir le lien reçu, se connecter avec l'adresse invitée (ou **Créer mon compte**),
puis **Rejoindre** l'établissement.

## Gérant
- **Paramètres** : nom sur les reçus, adresse, téléphone, logo, caisses.
- **Équipe** : inviter, changer un rôle, ajuster un droit, désactiver un accès.
- **Articles** : créer, modifier, importer un tableur (modèle fourni).
- **Stock** : entrée de marchandise, ajustement avec motif, inventaire.
- **Ventes** : annuler une vente (motif obligatoire, caisse encore ouverte).
- **Clôtures** : compter la caisse et éditer le ticket Z (définitif).
- **Tableau de bord** : chiffre d'affaires, marge, encaissements, stock bas.

## Caissier
1. **Caisse → Ouvrir la caisse** avec le fond de caisse.
2. Ajouter les articles, saisir le montant versé et le mode de paiement, **Valider la vente**.
3. Le reçu s'affiche (**Imprimer**) ; **Nouvelle vente** pour continuer.
4. Vente à crédit : choisir le client (module Contacts) ; le reste dû s'encaisse plus tard depuis **Ventes → Encaisser le reste**.

## Comptable
**Dépenses** (avec justificatif), **Ventes** et leurs paiements, **Tableau de bord** et tickets Z (**Clôtures**).

## Bon à savoir
- Une vente validée ne se modifie pas : on l'annule avec un motif, tout reste tracé.
- Si un bandeau « licence » apparaît, contacter Agence Elite.
