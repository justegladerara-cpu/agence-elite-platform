# Demande « 150 fonctions » du 2026-10-09 : classement honnête

Source : message de Juste du 2026-10-09 15:09 UTC (« aplliques tout et ameliores tout le systeme »).
Ce document classe chaque fonction avant de construire. Rien n'est marqué « Déjà là » sans preuve dans le code.

Légende :
- **Déjà là** : existe et fonctionne de bout en bout (preuve = fichier ou table).
- **Partiel** : la base existe, il manque une partie (dite).
- **À construire (lot X)** : prévu dans un lot ci-dessous.
- **Bloqué : raison** : impossible sans une décision ou un accès de Juste.

Rappel : un envoi réel (email, SMS, WhatsApp, paiement en ligne, signature à valeur légale) dépend d'un
fournisseur qui n'est pas encore choisi (voir `docs/INTEGRATIONS.md`, lot 5). Ces lignes sont « Bloqué » tant que
le fournisseur n'est pas choisi et testé sur son bac à sable. Le reste peut être construit.
