# Décisions — 8 octobre 2026

| Contexte                    | Décision                                                                 | Alternatives et justification                                                                                                                                                   |
| --------------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Dépôt presque vide          | Application autonome dans sites-clients/express-congo                    | Pas de remplacement des fichiers racine ni mélange avec d’autres clients                                                                                                        |
| Stack                       | Next.js 16.4.0, React 19.3.0, TypeScript strict                          | Versions vérifiées sur le registre et verrouillées ; TypeScript 7 incompatible avec typescript-eslint, retour à 6.0.3                                                           |
| Reprise sans compte externe | SQLite Node natif comme adaptateur local                                 | PostgreSQL Docker seul rendrait le lancement impossible sur cet hôte sans Docker. Schéma PostgreSQL préparé pour la cible ; aucun raccordement de production annoncé            |
| Calcul                      | Fractions d’entiers BigInt, décimales françaises jusqu’à 6 chiffres      | Évite l’accumulation d’erreurs binaires et les arrondis commerciaux prématurés                                                                                                  |
| Prix                        | Règles pures, centimes entiers, aucune règle active                      | Ne pas interpréter le prix maritime ambigu ni inventer un diviseur volumétrique                                                                                                 |
| Documents                   | Stockage transactionnel privé en BLOB, quarantaine intégrale             | Aucun téléchargement tant que l’analyse et l’autorisation documentaire ne sont pas vérifiées                                                                                    |
| Design                      | Bleu #143F86, rouge boutons #C71922, logo original                       | Rouge assombri pour contraste du texte blanc. Palette proposée, jamais présentée comme charte officielle                                                                        |
| Typographie                 | Inter auto-hébergée, licence OFL conservée                               | Aucun téléchargement de police au build, aucun appel Google Fonts à l’exécution                                                                                                 |
| Visuels                     | Bannières source à dimensions modérées                                   | Aucune photo ni partenariat inventé, droits inscrits EC-006                                                                                                                     |
| Environnements              | Démo par défaut, build production bloqué jusqu’à validation/raccordement | Préserve les données non validées et évite une fausse plateforme prête à publier                                                                                                |
| Édition                     | Propositions texte rendues comme texte React, session opaque locale      | Pas de HTML utilisateur, pas de mot de passe de démonstration utilisable en production                                                                                          |
| Redirection PDF             | Anciennes URL vers /tarifs tant qu’aucune grille n’est validée           | Aucun téléchargement ne présente la source historique comme une offre applicable. Remplacer par un PDF versionné après EC-012                                                   |
| Communication               | Aucun envoi réel ni déploiement                                          | Le cahier des charges exclut expressément ces actions                                                                                                                           |
| URL (reprise Claude)        | `trailingSlash: true`                                                    | Les URL indexées du WordPress portent une barre finale (/a-propos/, /services/…). Sans elle, chaque ancienne page redirigeait et l’article de mesures faisait deux sauts (§6.1) |
| Horaires et réseau observés | Ajoutés au contenu avec statut OBSERVÉ, masqués en production            | Horaires publiés sur /contact/ et page Facebook relevés le 8 octobre 2026 ; restent soumis à EC-003 et EC-005                                                                   |

Le noyau opérationnel utilise des comptes fictifs préétablis, scrypt et des sessions hachées avec permissions par propriétaire/agence. Le second facteur administrateur est explicitement une simulation ; la cible exige encore Auth éprouvée/MFA. ESLint reste en 9.39.5 pour respecter les versions prises en charge par les plugins Next ; TypeScript est en 6.0.3. npm, utilisé pour préparer cette machine sans CLI standard, a été retiré des dépendances du projet.

## Refonte visuelle et logiciel de gestion — reprise Claude, 8 octobre 2026

| Contexte                                 | Décision                                                                                                                                    | Alternatives et justification                                                                                                   |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Design jugé trop générique par le client | Typographie large Archivo (OFL, auto-hébergée) pour les titres, Inter pour le texte ; bleu nuit #0B1D3F dominant, rouge réservé aux actions | Évoque la signalétique aérienne et portuaire du fret. Aucune police distante (CSP font-src self)                                |
| Bannières du site actuel                 | Non réutilisées en premier écran ; tracé schématique Paris → Brazzaville / Pointe-Noire en SVG, positions tirées des coordonnées réelles    | Montages basse résolution ; la bannière aérienne montre une compagnie identifiable, interdit comme preuve de partenariat (§2.2) |
| Numérotation 01/02/03 des services       | Supprimée ; conservée pour les quatre étapes                                                                                                | Les services ne sont pas une séquence                                                                                           |
| Back-office « type Zoho Books »          | Application à barre latérale groupée, tableau de bord, fiches latérales, filtres, export CSV, rapports                                      | Les chiffres viennent uniquement des dossiers visibles par le rôle ; aucun indicateur fictif                                    |
| Demandes web dans la gestion             | `src/server/backoffice.ts` : vue filtrée par rôle et agence, changement d’état hors transaction des opérations                              | Même connexion SQLite que `operation()` : une transaction imbriquée bloquerait                                                  |
| Graphiques                               | Une seule série par graphique, une teinte, valeurs visibles et info-bulle                                                                   | Pas de palette catégorielle à valider ; états avec libellé et couleur de statut                                                 |
| Export CSV                               | Généré dans le navigateur à partir des lignes déjà autorisées par le serveur, séparateur « ; », BOM UTF-8                                   | Ouverture directe dans Excel français ; aucun export de données hors périmètre                                                  |
| Applications installables                | Deux manifestes, icône tirée du « E » rouge du logo officiel, sans service worker                                                           | Pas de cache hors ligne de documents privés (§14)                                                                               |
| Réception d’un colis                     | Mesures déclarées et mesurées en deux blocs, dimensions mesurées facultatives (reprennent les déclarées)                                    | Comble l’écart signalé dans HANDOFF : l’API acceptait déjà toutes les dimensions contrôlées                                     |

## Mise en ligne Cloudflare — 8 octobre 2026

| Contexte                                          | Décision                                                                                                                                                                 | Alternatives et justification                                                                                                                                                                 |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Hébergement demandé : Cloudflare                  | Workers + adaptateur OpenNext 1.20.9, Worker `express-congo`                                                                                                             | Netlify écarté à la demande du client. Le Worker `agence-elite-platform` existant n’est pas touché                                                                                            |
| Persistance en ligne                              | Cloudflare D1 `express-congo-demo` (Europe de l’Ouest)                                                                                                                   | Même dialecte que SQLite local, aucun secret à copier. Supabase écarté : le projet existant contient les données réelles d’un autre produit et un nouveau projet serait payant                |
| Couche de données                                 | Interface `Sql` asynchrone : SQLite Node en local, D1 en ligne (`DATABASE_DRIVER=d1`)                                                                                    | Mêmes requêtes et mêmes tests sur les deux moteurs                                                                                                                                            |
| Pas de transaction interactive sur D1             | Lots atomiques (`batch`), clé d’idempotence unique, mises à jour conditionnelles, verrou de révision, limitation en une instruction (`INSERT … ON CONFLICT … RETURNING`) | Une transaction ouverte entre deux `await` mélangerait les requêtes concurrentes. Limite connue : une commande à plusieurs écritures (affectation à un départ) n’est pas entièrement atomique |
| Next.js 16.4.0 incompatible avec OpenNext 1.20.9  | Version figée à **16.3.8**                                                                                                                                               | 16.4 lit `.next/server/preview-props.json`, que l’adaptateur n’embarque pas (erreur 500 sur toutes les pages). Remonter de version seulement quand OpenNext le prend en charge                |
| Proxy Next (Node) non pris en charge par OpenNext | Contenus WordPress retirés servis en 410 par des routes dédiées ; `X-Robots-Tag` déclaré dans `next.config.ts`                                                           | Comportement identique, testé                                                                                                                                                                 |
| Contrôle d’origine derrière Cloudflare            | Origine comparée à `SITE_URL` si défini, sinon à l’en-tête `Host`                                                                                                        | L’URL interne vue derrière l’adaptateur différait de celle du navigateur (403 sur tous les envois)                                                                                            |
| Données de démonstration en ligne                 | Jeu généré via les API dans un D1 local, exporté puis inséré ; comptes recréés à la première connexion, journal d’activité vide au départ                                | Évite la recopie des empreintes de mots de passe ; aucune session ni compteur exporté                                                                                                         |

## Finalisation — 9 octobre 2026

| Contexte                | Décision                                                                     | Alternatives et justification                                                                                                                                                         |
| ----------------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Code de suivi public    | HMAC-SHA256 de l’identifiant interne, 8 caractères sans 0/O/1/I              | Pas de colonne ni de migration D1 ; un code stocké aurait exigé de recalculer les dossiers existants. Comparaison à temps constant, même réponse pour référence inconnue ou code faux |
| Emails sans prestataire | Message simulé affiché à l’écran, signalé comme tel                          | Ne jamais prétendre qu’un email est parti ; le parcours complet reste testable                                                                                                        |
| Total des propositions  | Calculé côté serveur à partir des lignes, BigInt                             | Le navigateur affiche un aperçu ; le serveur ne fait jamais confiance au total saisi                                                                                                  |
| Transfert d’agence      | Interdit entre le départ et l’arrivée                                        | Un dossier en transit reste sous la responsabilité de l’agence de départ                                                                                                              |
| Contenus officiels      | Repris du site expresscongo.fr, mention de source, statut `PROPOSÉ` conservé | Le client a désigné ce site comme source ; la validation formelle EC-026 reste nécessaire avant production                                                                            |
| Design                  | Couche `premium.css` séparée                                                 | Montée en gamme réversible, sans réécrire `globals.css`                                                                                                                               |

## Tarifs et paiements — 9 octobre 2026 (soir)

| Contexte                               | Décision                                                      | Alternatives et justification                                                           |
| -------------------------------------- | ------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| Grille transmise par le client         | Publiée telle quelle, une seule source (`tariffs.ts`)         | Évite les écarts entre page, estimation et propositions                                 |
| Ligne maritime « 800 » sous « € / Kg » | Lue comme 800 € pour 1 m³, mention visible sous le tableau    | 800 € le kilo est incohérent avec 13 € le kilo en aérien ; validation demandée (EC-012) |
| Estimation                             | Seulement fret aérien avec douane (prix unitaires)            | Les autres lignes sont « sur devis » dans la grille                                     |
| Coordonnées bancaires                  | Saisies dans le hub par l’administrateur, affichées au client | Ce sont des informations destinées aux payeurs ; l’IBAN est contrôlé par sa clé         |
| Clés des prestataires                  | Secrets Cloudflare uniquement, présence seule affichée        | Une clé secrète ne doit jamais transiter par un formulaire ni la base                   |
| Encaissement                           | Saisie manuelle plafonnée, sur proposition acceptée           | Le paiement automatique viendra avec un webhook authentifié                             |
| Écritures multiples sur D1             | Lot unique avec garde de révision (`REQUIRE_CHANGE`)          | D1 n’a pas de transaction interactive ; le lot est annulé en entier si un verrou échoue |

## Rattachement à la plateforme — 9 octobre 2026 (soir)

| Contexte                             | Décision                                                                                                                  | Alternatives et justification                                                                                                                                               |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Gérer les accès depuis la plateforme | API `/api/plateforme/*` appelée par le navigateur du Super Admin avec son jeton Supabase, vérifié par `est_super_admin()` | Un secret partagé aurait dû être créé dans deux projets Cloudflare et ne marche pas sur le Worker statique de la plateforme ; ici la base de la plateforme reste seule juge |
| Création de compte                   | Lien d’activation (72 h, usage unique), aucun mot de passe provisoire                                                     | Le Super Admin ne connaît jamais le mot de passe ; rien de sensible à transmettre hormis un lien qui expire                                                                 |

| Démo publique                        | Ouverte par défaut, fermable depuis la plateforme                                                                         | Garde la présentation commerciale possible, mais coupe d’un clic l’accès administrateur public                                                                              |
